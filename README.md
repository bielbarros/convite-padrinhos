# 💍 Convite Interativo para Padrinhos de Casamento

Este projeto foi desenvolvido como uma forma criativa e divertida de convidar amigos para serem padrinhos de casamento. Ao invés de um convite tradicional, criamos uma página web interativa com um toque de humor e animações envolventes.

##  Funcionalidades

- **Interface responsiva e moderna** com estilo elegante inspirado nas cores do casamento:
  - Terno cinza claro
  - Madrinhas com vestido fúcsia
  - Padrinhos com terno azul-marinho
- **Botão "Sim" com animação pulsante**, incentivando a resposta positiva 
- **Botão "Não" que foge do cursor**, tornando quase impossível clicar 
- **Disparo de confetes** ao aceitar o convite 🎉
- **Redirecionamento automático para o WhatsApp** com mensagem pronta de confirmação
- **Imagem de fundo personalizada** representando o clima romântico da ocasião

## 🛠 Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- **[Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)** para o efeito de celebração
- Sem frameworks – projeto feito 100% na mão!

## 📌 Observações
O botão "Não" está configurado para funcionar apenas no desktop, utilizando o evento mouseover.

Ainda não foi implementado o suporte mobile para o botão "Não", pois o evento de hover não se aplica ao toque. (Futuramente poderá ser adaptado com eventos touchstart ou touchmove.)
